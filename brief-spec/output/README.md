# Multi-model design review corpus

This directory contains the independent LLM reviews requested during the
design of the Brief-Spec `0.5.0` and Human Continuity roadmap. One Markdown file
is retained per named model. `brief-spec-ultimate-plan.md` is the synthesized
plan derived from those reviews and repository evidence.

These files are design inputs, not runtime exports, canonical specifications,
test evidence, or publication proof. Implemented behavior is defined by the
source, schemas, tests, maintained documentation, and verification truth
boundary. New reviews should use a normalized model filename and must not
overwrite another model's response.
