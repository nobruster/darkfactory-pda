# Type 01 Gold at paid grain batch_id + currency

## Goal

Gold is the governed recon that may later be served. Grain is
`batch_id` + `currency`. Rebuild from landing. Do not read PostgreSQL
to compute the number.

## Behavior

- **B-1** — One Gold row per (`batch_id`, `currency`) for accepted landing.
- **B-2** — `valid-minimal` is `MATCHED`, applied_net `173.45`, amount_delta `0.00`.
- **B-3** — SQL does not reference `postgres`, `reporting.`, or Java.

## Success Criteria

```bash
ROOT="$(git rev-parse --show-toplevel)"
G="$ROOT/modern/dbt/models/gold/gold_card_settlement_reconciliation.sql"

eval_1() {
  test -f "$G" || return 1
  grep -q 'currency' "$G" || return 1
  grep -q 'applied_net_amount' "$G" || return 1
  grep -q 'MATCHED' "$G" || return 1
  ! grep -qiE 'postgres|reporting\\.|java' "$G" || return 1
}

eval_2() {
  python3 - "$ROOT" <<'PY'
import os, sys, subprocess
from pathlib import Path
root = Path(sys.argv[1])
os.environ.setdefault("NWP_TOKENIZATION_KEY", "northwind-pay-edp-fixture-key-v1")
script = root / "modern/scripts/run_type01_gold.py"
assert script.is_file(), script
subprocess.check_call([sys.executable, str(script)], cwd=root)
import duckdb
db = root / "modern/lakehouse/ducklake/northwind_modern.duckdb"
con = duckdb.connect(str(db), read_only=True)
row = con.execute(
    "select batch_id, currency, applied_net_amount, amount_delta, status "
    "from gold.gold_card_settlement_reconciliation "
    "where batch_id = 'B202607230000001'"
).fetchone()
assert row is not None, "missing gold row"
assert str(row[1]) == "BRL"
assert str(row[2]) == "173.45"
assert str(row[3]) == "0.00"
assert str(row[4]) == "MATCHED"
missing = con.execute(
    "select count(*) from gold.gold_card_settlement_reconciliation "
    "where batch_id = 'B202607230000004'"
).fetchone()[0]
assert missing == 0, "lie must not reach Gold"
print("gold ok", row)
PY
}
```
