Foundations · before the layers

What is a lakehouse?

Three generations of the same wish — store everything, query anything, trust the answer. Each era got two out of three. Tonight’s plant runs the third generation, locally.

2000s

Data Warehouse

structured only

Tables and SQL, governed and fast — but structured data only, expensive storage, rigid schemas.

SQL Server · Oracle · Teradata
2010s

Data Lake

all formats, no promises

CSV, JSON, Parquet on cheap object storage — but no ACID, no schema enforcement. Schema on read means surprises on read.

HDFS · S3 · Azure Data Lake
2020s

Data Lakehouse

both, governed

Open files + ACID + SQL + schema enforcement, in an open table format. The lake’s reach with the warehouse’s trust.

Delta Lake · Iceberg · DuckLake — tonight
Warehouse → Data Lake → Lakehouse Store everything, query anything, trust the answer — ours is DuckLake / DuckDB, local. The medallion layers live inside it.
