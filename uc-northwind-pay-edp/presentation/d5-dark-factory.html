Stage · context · the autonomy ruler · zero to five

The autonomy ruler — and which rung tonight is

Modelled on the driving-automation levels. Tuesday to Thursday the room sat on L3 and L4: reviewer, then the seat that leaves. Tonight is the last rung — no engineer writes, no engineer reviews, the gate decides.

L0 Spicy
autocomplete the car has cruise control You start the line, it finishes it. Tab-completion with opinions. The code is unambiguously yours. a faster keyboard
L1 The coding
intern lane-keeping One discrete, well-scoped task at a time — boilerplate, a unit test, a docstring — and you read every line before merge. you still move at typing speed
L2 The junior
developer autopilot on the motorway Multi-file, multi-module work; you pair in flow and still review every line. Shapiro's estimate: ~90% of self-described “AI-native” developers are here. it feels finished — it isn't
L3 The
developer a Waymo with a safety driver You write the spec; the agent writes most of the code; you become a full-time reviewer with several tabs open. Your life becomes diffs. Tue · Wed: you reviewed every diff
L4 The engineering
team a robotaxi You are the manager or the PM: you collaborate on specs and plans, walk away, and evaluate outcomes instead of reading code. You trust the system's own checks. Thursday: the seat that leaves
L5 The dark
software factory not a car any more No engineer writes code. No engineer reviews code. Humans write the spec and judge the outcome. A black box that turns specs into software — “dark” as in the Fanuc dark factory, where humans are neither needed nor welcome. Teams under five people. tonight · a sealed type, 0–8, lights out ✦ specs in · software out
L3 · L4 · done this week L5 · tonight

L5 is not "more L4". It is the point where nobody is on the floor and the only human hands are on the approval gate and the packet.

Stage · context · governance · how a rung is earned

Autonomy is a curve you climb, not a switch you flip

Tonight is L5 because the week earned it: one batch at a time, every step reversible, and a referee that has already said no. The lights go out because the evidence allows it, not because someone pressed a button.

climb a level when
▸Reversible — you can undo it without a meeting.
▸Small blast radius — one batch, one type, one branch.
▸A strong eval — golden_match.py has already said no. Twice.
drop a level the moment
✕Irreversible — legacy/ edited, expected/ rewritten, a sign recut.
✕Wide blast radius — the whole ledger, the whole cluster.
✕A weak eval — "it loaded" with no classification.

◆The sign at Consensus and the acceptance criteria.

Debrief · the flywheel, in principle · the one thing L5 does that L4 cannot

The factory doesn't only execute — it learns from what it executes

Every run leaves a lesson. Lessons become memory — notes on disk, not vibes. A lesson that keeps recurring gets promoted to a skill: a folder with instructions, references and scripts the agent loads only when the task needs it. Better skills make better agents; better agents run better executions.
