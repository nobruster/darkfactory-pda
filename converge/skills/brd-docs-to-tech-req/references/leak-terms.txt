# leak-terms.txt — premature-technology / stack terms for the Pass 1 leak scan.
#
# Pass 1 stays above the stack: naming a technology in a tech-spec is the most
# common Pass 1 failure (the stack is decided in Pass 3). check-tech-spec.sh
# loads this file and WARNs on every hit, naming the domain bucket.
#
# Format: one term per line, TAB-separated from its domain bucket:
#   term<TAB>domain
# Lines starting with '#' and blank lines are ignored. Terms are extended
# regex fragments matched case-insensitively with word boundaries (grep -wE),
# so 'spark' does NOT fire on 'sparkline' or 'Dana Sparks'. Because matching
# is word-boundaried, every term must START and END with a word character
# (a leading '[.]' can never match under -w).
#
# Buckets: data, web/frontend, infra/devops, ml/agents.
